Android Studio: Исправление бага с окном Proxy Authentication

Как навсегда убрать бесконечно всплывающее окно логина и пароля прокси, даже если прокси не требует пароля или нажата галочка «Remember».

⚡ Способ 1: Автоматически через мини-программу (Рекомендуется)

Специально создана утилита AndroidStudio_Proxy_Fix.exe (размером всего 11 КБ), которая сама находит все установленные версии Android Studio на вашем ПК и настраивает их в один клик.


  1. Запустите AndroidStudio_Proxy_Fix.exe.
  2. Проверьте порт вашего прокси (по умолчанию 10809):
    Программа прокси Обычный HTTP-порт
    v2rayN / Xray / Incy 10809
    Clash / Mihomo Party / Flclash 7890
    NekoBox / Hiddify 2080 или 7890
  3. Нажмите кнопку «Применить исправление».
  4. В открытой Android Studio перейдите в Settings (Ctrl+Alt+S) → System Settings → HTTP Proxy и выберите «No proxy» (это нужно, чтобы отключить сломанный GUI-диалог).
  5. Перезапустите Android Studio.
Всё готово! Прокси работает напрямую на уровне JVM и Gradle, а окно авторизации никогда больше не побеспокоит.

🛠️ Способ 2: Ручной способ (без сторонних программ)

Если вы хотите всё сделать руками за 2 минуты:

1 Отключите прокси в интерфейсе

Откройте Android Studio → Ctrl + Alt + S (Настройки) → Appearance & Behavior → System Settings → HTTP Proxy.

Выберите радиокнопку «No proxy» и нажмите OK.

2 Передайте прокси напрямую виртуальной машине (JVM)

В меню Android Studio нажмите Help → Edit Custom VM Options...

В самый конец открывшегося файла вставьте строки (замените 10809 на ваш HTTP-порт, если он другой):

-Dhttp.proxyHost=127.0.0.1
-Dhttp.proxyPort=10809
-Dhttps.proxyHost=127.0.0.1
-Dhttps.proxyPort=10809
-Dhttp.nonProxyHosts=localhost|127.0.0.1
-Djdk.http.auth.tunneling.disabledSchemes=""
-Djdk.http.auth.proxying.disabledSchemes=""

Сохраните файл (Ctrl + S).

3 Настройте Gradle

Откройте файл C:\Users\<ВашеИмя>\.gradle\gradle.properties в любом Блокноте и добавьте:

systemProp.http.proxyHost=127.0.0.1
systemProp.http.proxyPort=10809
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=10809
systemProp.http.nonProxyHosts=localhost|127.0.0.1
systemProp.https.nonProxyHosts=localhost|127.0.0.1

4 Перезапустите Android Studio

При первом запуске может появиться системное предупреждение: «Studio is configured to not use an HTTP proxy, but Gradle is currently using these proxy settings...».

Отметьте галочку «Больше не показывать это окно» и нажмите «Yes».

🧠 Почему этот баг вообще происходит? (Технические детали)

В платформе IntelliJ / Android Studio класс IdeProxyAuthenticator проверяет наличие сохраненных данных в PasswordSafe. Когда прокси не требует пароля (или пароль пустой), метод getCredentials() возвращает null.

Из-за внутренней ошибки метод считает null поводом немедленно показать окно AuthenticationDialog пользователю. При этом сохранение через «Remember» на Windows часто сбоит из-за несовпадения имен хостов (127.0.0.1 vs localhost).

Перевод прокси на уровень параметров запуска JVM (-Dhttp.proxyHost) полностью обходит проблемный код окна авторизации, заставляя весь сетевой стек Java и Gemini работать стабильно и быстро.

Android Studio: Исправление бага с окном Proxy Authentication

Как навсегда убрать бесконечно всплывающее окно логина и пароля прокси, даже если прокси не требует авторизации или нажата галочка «Remember».

⚡ Способ 1: Автоматически через AndroidStudio_Proxy_Fix.exe

Утилита сама находит все версии Android Studio на вашем компьютере и применяет исправление в 1 клик.


  1. Запустите AndroidStudio_Proxy_Fix.exe.
  2. Укажите порт вашего прокси (по умолчанию 10809):
    Программа проксиОбычный HTTP-порт
    v2rayN / Xray / Incy10809
    Clash / Mihomo / Flclash7890
    NekoBox / Hiddify2080 или 7890
  3. Нажмите кнопку «Применить исправление».
  4. В Android Studio: Settings (Ctrl+Alt+S) → System Settings → HTTP Proxy и выберите «No proxy» (это отключает проблемный Swing-диалог).
  5. Перезапустите Android Studio. Если появится окно с вопросом о сохранении настроек в gradle.properties — нажмите «Yes».
Готово! Прокси работает напрямую через параметры JVM и Gradle, а диалог авторизации больше не появится.

🛠️ Способ 2: Ручной способ

1 Отключите прокси в интерфейсе

В Android Studio перейдите в Settings → Appearance & Behavior → System Settings → HTTP Proxy, выберите «No proxy» и нажмите OK.

2 Добавьте прокси в VM Options

В меню нажмите Help → Edit Custom VM Options... и добавьте в конец:

-Dhttp.proxyHost=127.0.0.1
-Dhttp.proxyPort=10809
-Dhttps.proxyHost=127.0.0.1
-Dhttps.proxyPort=10809
-Dhttp.nonProxyHosts=localhost|127.0.0.1
-Djdk.http.auth.tunneling.disabledSchemes=""
-Djdk.http.auth.proxying.disabledSchemes=""

3 Настройте Gradle

В файле C:\Users\<Имя>\.gradle\gradle.properties укажите:

systemProp.http.proxyHost=127.0.0.1
systemProp.http.proxyPort=10809
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=10809
systemProp.http.nonProxyHosts=localhost|127.0.0.1
systemProp.https.nonProxyHosts=localhost|127.0.0.1

🧠 Почему возникает этот баг?

В платформе IntelliJ метод IdeProxyAuthenticator запрашивает учетные данные из PasswordSafe. Для прокси без аутентификации метод возвращает null. Из-за архитектурного изъяна IntelliJ считает null поводом немедленно показать пользователю окно ввода пароля.

Прямая передача параметров в JVM (-Dhttp.proxyHost) полностью обходит проблемный класс PlatformProxyAuthentication.

Android Studio: Fix Recurring Proxy Authentication Dialog

Permanently resolve the infinite proxy credential popup loop, even when using an unauthenticated proxy or when "Remember password" is checked.

⚡ Method 1: Automatic via AndroidStudio_Proxy_Fix.exe

The standalone tool automatically scans all Android Studio installations and patches the configs in 1 click.


  1. Launch AndroidStudio_Proxy_Fix.exe.
  2. Verify your proxy HTTP port (default is 10809):
    Proxy ClientCommon HTTP Port
    v2rayN / Xray / Incy10809
    Clash / Mihomo / Flclash7890
    NekoBox / Hiddify2080 or 7890
  3. Click "Apply Fix".
  4. In Android Studio: Settings (Ctrl+Alt+S) → System Settings → HTTP Proxy and select "No proxy" (disables the bugged Swing dialog).
  5. Restart Android Studio. If prompted to keep Gradle proxy settings in gradle.properties, select "Yes".
Done! Traffic routes cleanly via JVM and Gradle without modal interruptions.

🛠️ Method 2: Manual Configuration

1 Disable GUI Proxy

In Android Studio: Settings → Appearance & Behavior → System Settings → HTTP Proxy, choose "No proxy" and click OK.

2 Supply Proxy via Custom VM Options

Go to Help → Edit Custom VM Options... and append:

-Dhttp.proxyHost=127.0.0.1
-Dhttp.proxyPort=10809
-Dhttps.proxyHost=127.0.0.1
-Dhttps.proxyPort=10809
-Dhttp.nonProxyHosts=localhost|127.0.0.1
-Djdk.http.auth.tunneling.disabledSchemes=""
-Djdk.http.auth.proxying.disabledSchemes=""

3 Configure Gradle

In C:\Users\<User>\.gradle\gradle.properties add:

systemProp.http.proxyHost=127.0.0.1
systemProp.http.proxyPort=10809
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=10809
systemProp.http.nonProxyHosts=localhost|127.0.0.1
systemProp.https.nonProxyHosts=localhost|127.0.0.1

🧠 Root Cause Explanation

In IntelliJ Platform, IdeProxyAuthenticator requests credentials from PasswordSafe. When authentication is disabled, it returns null. The IDE mistakenly treats null as "credentials not yet entered", continuously triggering AuthenticationDialog.

Configuring proxy via JVM system properties bypasses PlatformProxyAuthentication entirely.

Android Studio: 彻底解决代理认证弹窗不断弹出的问题

彻底修复即使无需认证或勾选“记住密码”后，IDE 仍无限次弹出代理用户名和密码窗口的问题。

⚡ 方法 1：使用 AndroidStudio_Proxy_Fix.exe 自动修复

工具会自动查找电脑中所有版本的 Android Studio，一键自动配置完成。


  1. 运行 AndroidStudio_Proxy_Fix.exe。
  2. 输入本地代理 HTTP 端口（默认 10809）：
    代理软件常见 HTTP 端口
    v2rayN / Xray / Incy10809
    Clash / Mihomo / Flclash7890
    NekoBox / Hiddify2080 或 7890
  3. 点击 “应用修复”（Apply Fix）。
  4. 在 Android Studio 中：Settings (Ctrl+Alt+S) → System Settings → HTTP Proxy，选择 “No proxy”（关闭异常的 UI 弹窗）。
  5. 重启 Android Studio。若弹出是否在 gradle.properties 中保留代理设置，选择 “Yes”。
修复完成！ 代理直接在 JVM 与 Gradle 层生效，不会再有任何烦人弹窗。

🛠️ 方法 2：手动配置

1 在设置中关闭 UI 代理

打开 Android Studio → Settings → System Settings → HTTP Proxy，勾选 “No proxy” 并点击 OK。

2 在 VM Options 中配置 JVM 代理

点击菜单栏 Help → Edit Custom VM Options...，在末尾添加：

-Dhttp.proxyHost=127.0.0.1
-Dhttp.proxyPort=10809
-Dhttps.proxyHost=127.0.0.1
-Dhttps.proxyPort=10809
-Dhttp.nonProxyHosts=localhost|127.0.0.1
-Djdk.http.auth.tunneling.disabledSchemes=""
-Djdk.http.auth.proxying.disabledSchemes=""

3 配置 Gradle

打开 C:\Users\<用户名>\.gradle\gradle.properties 文件并添加：

systemProp.http.proxyHost=127.0.0.1
systemProp.http.proxyPort=10809
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=10809
systemProp.http.nonProxyHosts=localhost|127.0.0.1
systemProp.https.nonProxyHosts=localhost|127.0.0.1

🧠 原理分析

IntelliJ 内部的 IdeProxyAuthenticator 会向 PasswordSafe 请求凭据。在不需要认证的代理上，该方法返回 null，而框架错误地将 null 判定为“用户尚未输入密码”，导致每次网络请求都强制弹出 Swing 认证对话框。

通过 JVM 参数直连代理可以完全绕过异常的 PlatformProxyAuthentication 模块。

Android Studio: Fix Recurring Proxy Authentication Dialog

Permanently resolve the infinite proxy credential popup loop, even when using an unauthenticated proxy or when "Remember password" is checked.

рџ§  Root Cause Explanation

In IntelliJ Platform, IdeProxyAuthenticator requests credentials from PasswordSafe. When authentication is disabled, it returns null. The IDE mistakenly treats null as "credentials not yet entered", continuously triggering AuthenticationDialog.

Configuring proxy via JVM system properties bypasses PlatformProxyAuthentication entirely.
